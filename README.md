# CloudFurm Site Export

## Upload to GitHub Pages
1. Unzip this archive
2. Upload **index.html** and the **assets/** folder to the repo root (same level)
3. Settings → Pages → branch `main` → folder `/ (root)`

## Local test
Do not open index.html as a file. Use a static server:
```
npx serve .
```
