UCC development log.

Current

Core gameplay is taking shape

🪙 Coin spawning and collecting🐾 Pet system⚡ Prestige

The main simulator foundation is being built around large coin objects, smaller collectible coins and pet multipliers. The project also includes a prestige system that provides a 0.25 multiplier.

  • Coin spawning and coin collection are implemented.
  • The pet system is usable and is still being polished.
  • Prestige is part of the progression systems being developed.
